# SwatchBook
hexcode based digital color management tool for Android.

enhance precision and uniformity in graphics processing workflows. a tool for book matching color in hexadecimal format [i.e. #000000]. pick colors from existing images, save swatches to a viewable gallery, and transfer data between aplications.

feature: organize swatches into custom albums and display as a full color collection board.

core: hex format database

values: 16,777,216 colors (htmlcolorcodes.com)
